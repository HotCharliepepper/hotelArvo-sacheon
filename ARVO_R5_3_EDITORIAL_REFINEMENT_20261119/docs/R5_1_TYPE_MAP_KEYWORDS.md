# ARVO R5.1 / KEEP THE ENERGY, REMOVE THE WEIGHT

기준: 2026-11-19 R5 소스. 별도 복사본에 적용한 시각 중심 수정. 운영 확정·공개 배포 아님.

## 확정 적용
- 현재 900에 고정된 디스플레이 영문 700으로 경량화, 시각적 크기 5~10% 축소. Arial Black 자체의 두꺼움 제거.
- 한글 대형 제목을 Noto Sans KR 계열 500~600으로 변경; Latin Display는 Space Grotesk 700.
- 기존 28초 선형 무한 애니메이션 `.ticker-inner`(Infinite Horizontal Marquee / Scrolling Ticker) 보존.
- 장소 정보는 LOCATION 아래 지도 + 실제 주소 + Google Maps 외부 링크로 묶음. 지도는 **주소 검색 iframe**이며 정식 업체 핀/현장 진입 동선/지도 로딩 검수가 필요함.
- 시그니처·트윈·2PC를 객실 설명에서 자연스럽게 쓰도록 정리.

## 키워드 첫 번째 세트 (검색량·검색 순위 미검증, 후보)

| 의도 | 후보 문구 | 삽입 위치 | 상태 |
|---|---|---|---|
| 브랜드 탐색 | 사천 아르보호텔 | HTML title·LOCATION h2·실제 주소 문장 | 주소/표기 운영 확인 후 공개 |
| 지역 숙소 탐색 | 사천 호텔, 사천 숙소 | 메타 설명과 고객 안내 문장에 필요 시 1회 | 검색량·실제 적합성 확인 후 |
| 객실 구성 탐색 | 사천 트윈 객실 | ROOM 소개 및 실제 매핑 완료 후 | 트윈 상품 매핑 미확정 |
| 객실 경험 탐색 | 사천 2PC 객실 | ROOM 소개 / 해당 사진 alt | 세부 기기 사양 미확정 |
| 특화 시설 탐색 | 사천 사우나 객실 | 실제 객실/상품 연결 및 이용 조건 검증 이후 | 보류 |
| 공항 접근 검색 | 사천공항 주변 숙소 | 위치 관계/교통 시간 확인 이후 | 보류 |

브랜드·주소·객실 내용은 사람이 읽는 한글 본문에만 자연스럽게 넣습니다. 메타 키워드 나열이나 숨겨진 키워드 사용 금지.

## 공개 전 게이트
1. 최신 영업 표기/정확한 업체 핀을 ARVO 운영자로부터 확인.
2. Google Maps의 실제 '공유 → 지도 퍼가기' HTML로 주소 검색 iframe을 교체, 모바일에서 핀과 길찾기 확인.
3. 운영정보 원장에 맞춰 객실 타입/판매 상품/사진을 매핑.
4. `noindex` 해제 여부, 운영 도메인, canonical, XML sitemap, Hotel/LocalBusiness JSON-LD를 승인 후 적용.
5. 네이버/GBP/OTA의 상호·주소·예약 경로가 같은지 점검.
6. 검색량은 네이버 광고 키워드 도구 및 실제 Search Console 자료로 검증.

## 테스트 의미
- 로컬 문법/파일 검수: 소스가 해석 가능함.
- 브라우저 QA: 화면/지도 로딩/터치/키보드 등은 실제 테스트 결과로 별도 기록.
- 지도 표시 자체가 GEO 또는 검색 순위 상승을 보장하지 않음.
