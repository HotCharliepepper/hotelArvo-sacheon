## 시행했지만 성공하지 못한 것

- Playwright/Chromium으로 로컬 `http://127.0.0.1:5304/`, `localhost`, `file://`에 진입하여 스크린샷과 실제 버튼 동작을 검수하려 했으나 브라우저가 `net::ERR_BLOCKED_BY_ADMINISTRATOR`로 진입을 거부함. **화면 실제 렌더링/모바일 작동/콘솔 에러가 없다고 주장하지 않음**.
- 같은 URL의 HTTP GET은 응답 `200 OK`로 확인. 서버 응답은 브라우저 UI QA를 대신하지 않음.
