기준일: 2026-11-19 KST  
대상: `dist/index.html`, `data.js`, `app.js`, `styles.css`의 정적 시안  
환경: Chrome에서 로컬 화면과 반응형 iframe을 이용한 검수

## 현재 판정

아래에 기록한 범위에서 화면 크기와 주요 행동을 확인했습니다. **실제 모바일 기기·보조기술·운영 예약의 검수를 완료한 상태는 아닙니다.** 디자인 시안의 동작 확인과 호텔 운영정보 확정·고객 공개 승인은 별도입니다.

반응형 검수의 1440·1366·390·320은 iframe의 **CSS 화면 너비(px)**입니다. 실제 휴대전화 하드웨어나 모바일 운영체제로 검수한 수치가 아닙니다.

## 코드 리뷰에서 확인한 사항

낮은 화면 높이에서는 이미지 영역 높이와 사진창의 헤더·캡션·탐색 버튼 높이를 합한 값이 모달의 최대 높이를 넘을 수 있었습니다. 해당 크기 충돌을 수정한 뒤 768 × 440px 환경에서 이미지와 하단 영역을 스크린샷으로 확인하고, 하단 영역 DOM 좌표가 화면 높이 안에 있음을 확인했습니다.

수동 모션 설정과 루트 요소의 앵커 스크롤 사이에 적용 범위 차이가 발견되었습니다. 루트 요소에 설정을 반영하도록 수정한 뒤 수동 버튼 클릭 시 `html`의 `motion-off` 클래스와 버튼의 선택 상태·라벨이 함께 변경되는 것을 확인했습니다. OS 설정을 바꾸는 실기기 검수와는 별도 결과입니다.

## 전달 파일 검수

단일 HTML은 5,169,708바이트이며, 초기 표시 사진·폰트·CSS·스크립트와 동적 객실 사진을 포함한다. 브라우저의 로컬 HTTP에서 해당 파일의 실행을 확인했다. 사용자의 PC에서 file://로 직접 여는 실환경 검수는 아직 수행하지 않았다. 외부 OTA·지도 탐색을 제외한 정적 자원은 파일 내부 data URL로 포함한다.

검수 화면은 `screenshots/`에 보관했다. 데스크톱 캡처는 1348px, 모바일 캡처는 CSS 너비390px iframe의 화면이다. `serve.mjs`는 구문·코드 검토를 수행했고, 이번 실제 화면 검수는 관리형 정적 미리보기에서 수행했다.
