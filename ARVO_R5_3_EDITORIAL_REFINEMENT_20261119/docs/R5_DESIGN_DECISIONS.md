# ARVO R5 디자인 결정 — STAY YOUR WAY

## 목적

R4.2의 사진 중심 정적 안내를 **호텔 자체가 레퍼런스로 보일 수 있는 비주얼 경험**으로 고도화한다. 이번 단계의 목표는 시각적인 수준과 모션·객실 선택의 조합이며 백엔드·GEO 키워드의 확정 적용은 별도 단계다.

## 장면별 역할

1. **HERO:** 객실 사진 위 대형 `STAY YOUR WAY.`와 `하나의 호텔, 서로 다른 하루.` — 방문자의 첫 인상
2. **MANIFESTO:** 큰 한글 편집 서체와 실제 침실·조명 사진 — 브랜드의 온도
3. **ROOM EDIT:** 세 객실 카드가 선택에 반응하여 가로 폭/명암/타이틀이 변화 — 사용자에게 맞는 객실 탐색
4. **THE FEELING:** 욕실·목재 소재의 장면 전환 — 감각적 휴식
5. **CLOSER LOOK:** 객실/입구/조명 세부 컷을 사진 갤러리로 — 사진의 신뢰
6. **LOCATION:** 출입구와 주소, 미확인 운영정보를 확정하지 않는 FAQ — 도착의 불편 감소
7. **BOOKING:** 가장 마지막 큰 CTA와 상시 상단 예약 안내 — 예약 채널에서 현재 날짜·상품 확인

## 기술적 구현

- 빌드 의존성 없는 HTML·CSS·JavaScript, R4.2 선택·모달 접근성 로직 유지
- CSS 스크롤 reveal, 사진 탭 active expansion, 장면별 대비 및 선택 시 사진 전환
- `prefers-reduced-motion`과 수동 `움직임 줄이기` 기능
- 390px 이하에서는 카드가 가로로 넘어가는 스냅 갤러리
- 사진은 원래 공간을 변경하지 않고 R4.2 자산만 사용
- 검색 노출 방지를 위한 `noindex`; 공개 권한 부여/보안 접근제어 수단은 아님

## 더 고도화할 때의 경계

- 지금의 모션은 CSS 전환 중심. 필요하면 GSAP를 부가하되 성능과 접근성을 먼저 검수
- 본 계약의 공식 안내형 1페이지와 R5 레퍼런스 고도화의 범위를 구분
- 확정된 객실 매핑/이용 인원/시설/주차/취소 조건만 게시용 버전에 입력
- 사용자 공개 배포, 리뷰/문의 이벤트 추적, 직접예약·결제는 이번 범위 아님
